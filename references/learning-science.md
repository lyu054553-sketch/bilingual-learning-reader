# 学习设计依据与边界

本 Skill 用认知心理学和学习科学的实验结果指导功能选择。下面的论文直接测量了记忆或学习表现；它们没有验证这套阅读器，也没有证明某种页面颜色、排版或复习公式能改变特定脑区。介绍产品时使用“借鉴检索练习与间隔学习研究”，不使用“神经科学认证”“提高记忆力若干倍”等表述。

## 有证据的原则，以及本产品的取舍

### 1. 读过以后，尝试回忆

**直接证据：** 学生读短文后进行回忆练习，在延迟测验中的记忆表现优于同等次数的重读；短时测验与延迟测验的结果并不相同。眼前读得顺、感觉熟悉，不能直接表示过几天仍能记住。[Roediger 与 Karpicke，2006，原始论文](https://learninglab.psych.purdue.edu/downloads/2006/2006_Roediger_Karpicke_PsychSci.pdf)。

**产品应用：** 章节末提供可跳过的回忆问题，答案先收起。让读者先用自己的话回答，再查看参考要点和原文依据。题目围绕主张、原因、条件或例子；不能只问是否看过，也不能把练习次数显示成掌握程度。

### 2. 词汇复习需要真正尝试提取

**直接证据：** 一项斯瓦希里语—英语词对实验发现，第一次答对后继续进行提取练习，有助于一周后的回忆；实验中学习者对未来表现的预测也不能准确反映实际表现。这是特定词对任务的结果，不能直接当作英语口语、写作或全文理解的成效证明。[Karpicke 与 Roediger，2008，原始论文](https://learninglab.psych.purdue.edu/downloads/2008/2008_Karpicke_Roediger_Science.pdf)。

**产品应用：** 生词复习先显示英文，邀请读者回想文中意思；揭示后再显示释义、原句和译文，并选择“忘记 / 费力 / 较轻松”。这些是本次回忆的自评，不是能力分数。允许跳过，不把跳过算作忘记。句子帮助核对语境；不能把认出一个中文释义称为全面掌握该词。

### 3. 隔一段时间再复习，间隔可以调整

**直接证据：** 事实学习实验表明，复习间隔与最终测验距离共同影响保留效果；间隔并非越长越好，最佳间隔也不是对所有目标都一样。[Cepeda 等，2008，作者所在机构论文档案](https://escholarship.org/uc/item/0kp5q19x)。

**产品应用：** 保存上次自评与下次建议日期，允许读者改日期。默认间隔只是方便开始的启发式规则，必须能解释和修改；不称为已验证的个性化算法，也不称为对个人遗忘曲线的测量。提前或延后一天不应触发惩罚、断签或焦虑文案。

### 4. 先形成自己的答案，再看参考

**直接证据：** 生成效应实验中，学习者按线索和规则自己生成词语，比直接读到同样词语记得更好。实验使用了受约束的词语生成任务；它不能直接证明“随意造句一定比阅读有效”。[Slamecka 与 Graf，1978，作者提供的论文](https://www.researchgate.net/profile/Peter-Graf/publication/232485723_The_Generation_Effect_Delineation_of_a_Phenomenon/links/53f5eedf0cf2888a7491f9cb/The-Generation-Effect-Delineation-of-a-Phenomenon.pdf)。

**产品应用：** 译文按句揭示，为先尝试理解留下空间；词汇或章节中可提供简短的改述、填空、迁移使用提示，随后给可检查的参考。所有练习都能跳过或直接看答案。隐藏译文、自由造句和本页面的具体交互是设计推论，不能标为已由这项实验验证。

### 5. 帮助要容易找到，额外信息要有节制

**直接证据：** 电学与生物教材实验中，必须结合才能理解的分散信息整合后更利于学习；已经可独立理解的材料加入多余解释，有时反而妨碍学习。论文也说明未直接测量所提出的认知过程。[Chandler 与 Sweller，1991，原始论文](https://www.researchgate.net/profile/Paul-Chandler/publication/48828982_Cognitive_Load_Theory_and_the_Format_of_Instruction/links/0a85e5300f4b580df6000000/Cognitive-Load-Theory-and-the-Format-of-Instruction.pdf)。

**产品应用：** 原句与对应译文邻近，查词首先显示当前语境义，完整词典和补充例句逐层展开；复习时一次处理一个词。字号、对比度、留白和键盘操作服务于可读性与可访问性。黄色标注、三栏布局及具体字号是界面选择，不能冒充神经科学定律；译文对需要它的读者是必要帮助，不应一律视为冗余。

## Agent 生成学习内容时执行的规则

1. **保留读者控制。** 默认可直接双语阅读；需要挑战时切换到按句揭示。查词、练习和复习都不阻挡继续读正文，不能用倒计时强制等待答案。
2. **问题必须能核对。** 章节问题有简短参考答案及有效的原文句子编号。参考答案只覆盖文中支持的内容，保留条件与不确定性；开放问题注明参考角度，避免唯一标准答案的假象。
3. **区分词义与表达。** 重点词按当前语境解释，多义词保留不同例句。可建议用词改述本章观点，但需给含目标词的自然参考表达并标为补充示例。不要把词表学习宣称为完整的语言能力训练。
4. **先尝试，再核对。** 复习答案初始隐藏，自评入口在揭示后出现。看到答案后才想起时，不提示用户选“较轻松”。读者可以在心里回答；不把输入字数或是否打字当作学习质量。
5. **记录行为，谨慎解释。** 可以显示“本次复习了多少词”“还有多少到期”，避免“已经掌握”“记忆效率”“脑力分数”。收藏、翻译揭示、浏览进度均不自动变成掌握标记。
6. **日期与记录可携带。** 自评结果和复习日期随学习库同步，旧页面不能覆盖较新记录。浏览器未导出的变化仍需提示保存，不能用“智能记忆”掩盖数据未持久化。

## 后续怎样判断它真的有帮助

界面可用与学习有效是两项不同的检查。查词、揭示、导入导出成功，只能说明功能运行正常。若未来要声称学习收益，需要在取得参与者同意后比较相近难度与学习时长的条件，并设置延迟测验；例如数天后回忆词义和章节要点，另用新句子检查迁移。分别报告正确率、样本与时间间隔，不能用停留时间、收藏量或即时自评替代学习效果。

以上五项研究是功能设计依据。本 Skill 尚未经过独立的学习效果实验；也没有测量脑活动或验证个体化复习算法。
