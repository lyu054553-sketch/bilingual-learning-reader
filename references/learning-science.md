# 学习设计依据与边界

本 Skill 用认知心理学和学习科学的实验结果指导功能选择。下面的论文直接测量了记忆或学习表现；它们没有验证这套阅读器，也没有证明某种页面颜色、排版或复习公式能改变特定脑区。介绍产品时使用“借鉴检索练习与间隔学习研究”，不使用“神经科学认证”“提高记忆力若干倍”等表述。

## 有证据的原则，以及本产品的取舍

### 1. 词汇复习需要真正尝试提取

**直接证据：** 一项斯瓦希里语—英语词对实验发现，第一次答对后继续进行提取练习，有助于一周后的回忆；实验中学习者对未来表现的预测也不能准确反映实际表现。这是特定词对任务的结果，不能直接当作英语口语、写作或全文理解的成效证明。[Karpicke 与 Roediger，2008，原始论文](https://learninglab.psych.purdue.edu/downloads/2008/2008_Karpicke_Roediger_Science.pdf)。

**产品应用：** 生词复习先显示英文，邀请读者回想文中意思；揭示后再显示释义、原句和译文，并选择“忘记 / 费力 / 较轻松”。这些是本次回忆的自评，不是能力分数。允许跳过，不把跳过算作忘记。句子帮助核对语境；不能把认出一个中文释义称为全面掌握该词。

### 2. 隔一段时间再复习，间隔可以调整

**直接证据：** 事实学习实验表明，复习间隔与最终测验距离共同影响保留效果；间隔并非越长越好，最佳间隔也不是对所有目标都一样。[Cepeda 等，2008，作者所在机构论文档案](https://escholarship.org/uc/item/0kp5q19x)。

**产品应用：** 保存上次自评与下次建议日期，允许读者改日期。默认间隔只是方便开始的启发式规则，必须能解释和修改；不称为已验证的个性化算法，也不称为对个人遗忘曲线的测量。提前或延后一天不应触发惩罚、断签或焦虑文案。

### 3. 帮助要容易找到，额外信息要有节制

**直接证据：** 电学与生物教材实验中，必须结合才能理解的分散信息整合后更利于学习；已经可独立理解的材料加入多余解释，有时反而妨碍学习。论文也说明未直接测量所提出的认知过程。[Chandler 与 Sweller，1991，原始论文](https://www.researchgate.net/profile/Paul-Chandler/publication/48828982_Cognitive_Load_Theory_and_the_Format_of_Instruction/links/0a85e5300f4b580df6000000/Cognitive-Load-Theory-and-the-Format-of-Instruction.pdf)。

**产品应用：** 原句与对应译文邻近，查词首先显示当前语境义，完整词典和补充例句逐层展开；复习时一次处理一个词。字号、对比度、留白和键盘操作服务于可读性与可访问性。黄色标注、对照布局及具体字号是界面选择，不能冒充神经科学定律；译文对需要它的读者是必要帮助，不应一律视为冗余。

## Agent 生成学习内容时执行的规则

1. **直接阅读全文。** 保留原文顺序和双语对应，不生成章节分页、文章理解题、回答框或读后感。需要时按句揭示译文，查词和生词复习都不阻挡继续阅读。
2. **区分词义与表达。** 按当前语境解释，多义词保留不同例句。可补充自然的词汇例句并注明来源，不把词表学习宣称为完整的语言能力训练。
3. **先尝试，再核对。** 生词答案初始隐藏，自评入口在揭示后出现；原句可作提示，跳过不记错。
4. **记录行为，谨慎解释。** 可显示本次复习词数和到期词数，收藏、译文揭示及滚动位置不自动变成掌握标记。
5. **日期与记录可携带。** 自评和复习日期随学习库同步。浏览器未导出的变化需提示保存，不能承诺已持久化。

## 后续怎样判断它真的有帮助

界面可用与学习有效是两项不同的检查。查词、揭示、导入导出成功，只能说明功能运行正常。若未来要声称学习收益，需要在取得参与者同意后比较相近难度与学习时长的条件，并设置延迟测验；例如数天后回忆词义及搭配，另用新句子检查迁移。分别报告正确率、样本与时间间隔，不能用停留时间、收藏量或即时自评替代学习效果。

以上研究是功能设计依据。本 Skill 尚未经过独立的学习效果实验；也没有测量脑活动或验证个体化复习算法。
