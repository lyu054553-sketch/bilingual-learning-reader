# 内容整理规范

## 获取与范围

用户提供的全文、文档和字幕优先。链接只处理可获得的正文；不能用摘要冒充全文。正文无法取得、原视频非英语或字幕性质不明时说明条件，接受用户上传文件。仅在用户请求或授权下扩大到音频转写、登录内容或批量视频。原始文件保存到文章目录，不覆盖。

文章保留标题、段落、引用、列表及论证顺序，移除导航与页面推荐等外围内容。技术文档的代码和公式默认保留原样；复杂表格、图表可作为原始内容附件或在双语单元中保留必要结构，不能悄悄省略。若模板不能表示结构，按原布局补充对应内容区，并检查变化。

## 断句与对应

为原文片段与整理后的阅读单元分配稳定编号。每条整理单元记录原始片段范围或段落位置；字幕还记录近似起止时间。句子编号在同一文章内唯一，重新生成时尽量稳定。

字幕去重仅用于相邻滚动字幕的重叠部分，按词序和时间判断；正常重复表达不能删除。恢复标点、修复断行和自然断句，不默认改写发言或删掉整段。长句可按语义拆分，原始对应关系同时保留。疑似识别错误使用明确说明，不编造“已核对原音”。

## 翻译

每个英文阅读单元对应中文译文。准确、自然，保留条件、语气、不确定性、数字和重要细节。专业术语与人名先建立简短术语表，逐批沿用。没有识别出说话人时不要推测身份。

解释写入学习提示，不能混成原文译文。每批保存完成的对照数据，合并后检查编号连续、对应无缺失、章节覆盖和长文首尾。自动检查数字与覆盖不能替代语义检查。

## 重点词和词典

默认挑选适合雅思精读的学术词、论证表达及有用搭配，不硬规定词数或比例，不把整篇涂黄。用户可指定日常英语或专业英语。词族相关不等于词义相同，例如 collaboration、collaborate、collaborator 应按文中词性解释。

优先挑选理解本篇论证所必需、以后能再次使用的词与搭配。已知水平低时解释常见表达；已有词在新语境出现时优先展示区别。每个重点词有当前语境义和一个自然搭配；无把握的语义、专名或字幕错误不生成自动复习答案。多词搭配写入词汇笔记，不能为整句涂黄。普通词也能点击，缺词要明确说明。

使用现有可靠词库或来源，例如 ECDICT；读取其字段和许可说明，缓存到学习库可复用的位置，只把本篇需要的词条嵌入网页。包内 `assets/ECDICT-LICENSE.txt` 是 ECDICT 许可副本，使用该词库时将许可文本保留在网页数据中。没有词库时可由 Agent 根据上下文整理词汇笔记，但注明“Agent 整理”，不能冒充词典。音标和词性有可靠来源才提供。

词形归并使用可靠的原形信息，并结合语境检查多义情况；不要把 better、left、found 等机械地归入唯一含义。缩写、所有格和专有名词单独说明。一般释义与当前句子的语境义分开；`pair.meanings` 可为同词在不同句子提供不同语境义。

点击词的例句优先为点击位置的英文原句和译文；其他文章例句保留文章标题与来源。额外生成例句标明“补充例句”。未知内容明确提示。没有朗读、合成语音、原句音频或自动播放。

## 章节与已有收藏

优先使用原文结构或视频已有章节；否则按话题转折划分，标题简洁。章节数量和内容统计根据本篇计算。

重点词与用户收藏是不同状态。已有收藏可在文中显示细小的绿色标记，黄色仍表示学习重点。已有词遇到新语境可补充一条代表性例句；保留来源、词形和不同含义，不新增未经用户收藏的词条。

## 读后回想与迁移

按自然话题划分适合一次阅读的小节，不为凑固定时长切断推理。章节通常选择一到三个有价值的问题；篇幅很短、纯词表或没有可推理材料时可不出题。不要每句都弹题。

- 回忆题问“作者主张什么”“为什么”“限制条件是什么”，不能在题干里直接送出答案。
- 有合适内容时加入一个迁移提示，如换一种场景应用本章原则。明确“参考角度”，允许合理的不同答案。
- 每题保存 `question`、简短 `answer` 和 `evidence`（本章实际句子编号）。参考答案保留原文限制，解释和补充例子不冒充作者原话。
- 读者开始练习时暂时收起本节正文；先写或默想，再展开参考，可随时返回原文。
- 按句看译文和练习都是选项；译文始终可取得，不能设强制倒计时。草稿仅存在本页缓存，界面明确提示。

词汇复习使用已有收藏和原文语境，默认先隐藏中文；原句可作提示，查看答案后再自评。自评用于安排下一次练习，不显示“掌握率”或“能力分数”。具体研究依据和限制见 [learning-science.md](learning-science.md)。
